# Развёртывание: с нуля до работающей панели

**Проверено на:** Windows 11, Python 3.14, 1С 8.3.27.1508 (учебная), база `C:\1c_bases\DemoAgent`.
**Время:** 30–40 минут, из них 26 минут — построение RAG-индекса (если он нужен).

## 1. Что нужно

| Компонент | Требование | Зачем |
|---|---|---|
| Windows | 10/11 x64 | проверено на 11 (build 26200) |
| Python | 3.11+ (проверено 3.14) | панель, мост, инструменты |
| 1С:Предприятие | 8.3 (учебная или рабочая), файловая база | источник бизнес-данных |
| Ollama | локально, модели `vikhr-qd-a` или `qwen2.5:7b-instruct` | RAG-ответы (без него панель работает, чат по знаниям — нет) |
| Свободный порт | 8077 | панель |
| OPC UA сервер | **не требуется** | подключается позже заполнением конфига |

## 2. Копирование и зависимости

```powershell
# 1. проект целиком
xcopy /E /I D:\agent-1c-demo C:\agent-1c-demo

# 2. зависимости Python
cd C:\agent-1c-demo
py -m pip install chromadb sentence-transformers asyncua
# pywinauto нужен только для автозапуска 1С из скриптов:
py -m pip install pywinauto
```

## 3. База 1С

1. Создайте или откройте файловую базу (в демо — `ДемоАгент`).
2. Нужны объекты: `Справочник.Контрагенты`, `Справочник.Номенклатура`,
   `Документ.РеализацияТоваровУслуг` (реквизиты: Номер, Дата, Контрагент;
   табличная часть `Товары`: Номенклатура, Количество, Цена).
3. Если конфигурация другая — правьте запросы в `agent/panel_server.py`
   (блок `Q_*`), структура интерфейса не меняется.

## 4. Мост (внешняя обработка)

Готовая обработка: `C:\1c_bases\AgentMost_fixed.epf`. Если её нет или менялся
`1c/АгентМост.bsl` — пересобрать по `docs/epf_rebuild.md` (3 команды).

Открыть в 1С: **Файл → Открыть…** → `AgentMost_fixed.epf`, в поле пути указать
папку обмена (по умолчанию `D:\agent-1c-demo\exchange`), мост стартует сам.

## 5. Настройки

| Файл | Что задать |
|---|---|
| `agent/config.json` | `exchange_path`, `model`, `model_roles` |
| `agent/opcua_config.json` | `endpoint` и `nodes` — когда появится OPC UA; сейчас пусто |
| `agent/scada_config.json` | `scada_url`, если используется RapidSCADA HTTP API |

## 6. RAG-индекс (нужен для ответов по базе знаний)

```powershell
py rag\index_build.py --embedder multilingual   # ~26 минут, 15 600 документов
py rag\eval_retrieval.py --collection 1c_knowledge_v2 --embedder multilingual
```
Ожидаемый результат: hit@3 100%, MRR 0.85. Без индекса чат по знаниям честно
скажет «база знаний недоступна».

## 7. Запуск

```powershell
py tools\run_demo.py        # 1С с мостом + панель, печатает адрес
```

Открыть `http://127.0.0.1:8077`.

## 8. Приёмка после развёртывания

```powershell
py verify_1c.py             # протокол 1С
py tools\check_panel.py     # 26 проверок панели
py tools\rehearse.py --runs 1
```

Все три должны завершиться без ошибок. `check_offline.py` запускать осознанно —
он закрывает 1С.

## 9. Откат

Панель только читает. Чтобы вернуть систему в исходное состояние:

1. закрыть окно 1С с обработкой (или `taskkill /IM 1cv8t.exe /F`);
2. `py tools\panel_pid.py --kill`;
3. удалить каталог проекта — база 1С не изменилась.

Запись в 1С в текущей версии невозможна: обработка выполняет только `ВЫБРАТЬ`,
команды оборудованию отсутствуют в коде.

## 10. Отличия при развёртывании на предприятии

| Что | Как |
|---|---|
| Рабочая база | указать путь в настройках моста; права — только чтение |
| Пользователь 1С | отдельная учётная запись, без прав изменения |
| OPC UA | endpoint, политика безопасности, сертификат клиента (доверие на сервере), список узлов |
| Порт панели | 8077 на localhost; для доступа с других машин — обратный прокси с аутентификацией |
| Кто утверждает действия | роль-владелец процесса; до этого запись отключена |
