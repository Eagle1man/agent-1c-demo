# Демо: что показывать и что говорить

**Дата:** 01.11.2026
**Запуск:** `py tools\run_demo.py` → открыть `http://127.0.0.1:8077`
**Остановка:** закрыть окно 1С, затем `py tools\panel_pid.py --kill`

## Что показывает система

Один экран: состояние предприятия (из 1С), карточка документа, производство
(SCADA/OPC UA), чат. Данные — только из источников; при недоступности
показывается ошибка, а не числа.

## Сценарий на 5 минут

| № | Действие | Что должно быть на экране |
|---|---|---|
| 1 | Открыть панель | шапка: «1С: связь есть · мост 1.0», «SCADA/OPC UA: не подключён», время ответа |
| 2 | Посмотреть KPI | выручка ≈ 20,1 млн ₽, 385 документов, 12 контрагентов, средний чек |
| 3 | Посмотреть график | столбцы выручки по месяцам за 2 года, при наведении — сумма |
| 4 | Спросить в чате: **«какая выручка»** | сумма и среднее за месяц, источник 1С |
| 5 | Спросить: **«покажи последние документы»** | 5 последних документов с датами и контрагентами |
| 6 | Ввести в поиск **«Клевер»** | список документов этого контрагента |
| 7 | Кликнуть по строке | карточка: номер, дата, контрагент, проведён, позиции, итог |
| 8 | Блок «Производство · SCADA / OPC UA» | «OPC UA не подключён» + как подключить |
| 9 | Закрыть окно 1С и обновить | плашка «1С: НЕТ СВЯЗИ», числа `—`, причина |

Шаг 7 — самый важный для руководства: система **не придумывает** данные, когда
источник пропал.

## Что реально, а что нет

| Элемент | Статус |
|---|---|
| Данные 1С (385 документов, 12 контрагентов, 20 позиций) | **реальные**, из живой базы через файловый мост |
| Карточка документа и суммы | **реальные**, считаются из позиций документа |
| RAG-ответы | **реальные**, база 15 600 документов форума 1С |
| Чат: маршрутизация вопросов | детерминированная, по ключевым словам |
| Производство (SCADA/OPC UA) | **не подключено**: коннектор готов, сервер появится после развёртывания |
| Действия с записью в 1С | **отключены** (только чтение) |

## Что говорить про ограничения

- OPC UA-сервера на предприятии пока нет; адаптер написан под белый список узлов
  и включается заполнением `agent/opcua_config.json` — код не меняется.
- Запись в 1С и команды оборудованию отключены на уровне кода: демо ничего не
  может испортить в живой базе.
- Версия платформы в ответе моста — грубое указание семейства (`8.3`), не факт о
  сборке; вынесено в отдельную задачу.

## Чек-лист перед показом

```powershell
py tools\run_demo.py            # поднимет 1С и панель
py tools\check_panel.py         # 18 проверок, ожидается ИТОГ: OK
py verify_1c.py                 # приёмка протокола 1С
```

Если `check_panel` не проходит — показывать нельзя: сначала починить.
