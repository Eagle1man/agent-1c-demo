# Памятка на день показа

**Обновлено:** 01.11.2026
**Панель:** `http://127.0.0.1:8077` · **Проект:** `D:\agent-1c-demo`

## За 15 минут до показа

```powershell
cd D:\agent-1c-demo
py tools\run_demo.py            # поднимает 1С с мостом и панель
py tools\check_panel.py         # должно быть 26/26 OK
```

Дать панели **1–2 минуты прогрева**: при старте загружается модель эмбеддингов,
иначе первый вопрос к RAG займёт до полутора минут.

Проверка готовности: в шапке «1С: связь есть · мост 1.0», время свежее.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «1С: НЕТ СВЯЗИ» | окно 1С закрыто или обработка не открыта. Запустить: `py tools\epf\test_epf_live.py` |
| Панель не открывается | `py tools\panel_pid.py --kill`, затем `py agent\panel_server.py --port 8077` |
| Первый ответ RAG долгий | это прогрев модели; подождать один раз, дальше мгновенно |
| Числа `—` | так и должно быть при отказе: система не подставляет данные. Смотреть текст причины |
| «Порт занят» | `py tools\panel_pid.py --kill` (освобождает 8077) |
| Нужно пересобрать мост | `py tools\epf\put_module.py` → `LoadExternalDataProcessorOrReportFromFiles` (см. `docs/epf_rebuild.md`) |

## Проверки перед показом и после изменений

```powershell
py tools\check_panel.py      # 26 проверок панели

py tools\check_offline.py    # поведение при закрытой 1С (сам закроет 1С!)

```

**Важно:** `check_offline.py` закрывает 1С. После него поднять мост обратно:
`py tools\epf\test_epf_live.py`.

## Что говорить про отказ

Штатное поведение: при недоступной 1С панель показывает красную плашку с
причиной, числа заменяются на `—`, вопросы про данные отвечают «1С не ответила»,
а база знаний продолжает работать. Это проверено автоматически
(`tools/check_offline.py`), а не обещано.

## Ограничения, о которых стоит сказать сразу

- Запись в 1С и команды оборудованию отключены в коде — демо ничего не изменит в базе.
- OPC UA сервера пока нет; подключение предусмотрено и включается заполнением
  `agent/opcua_config.json`.
- Выгрузка CSV ограничена 50 строками на файл — ограничение моста, подписано в файле.
- Версия платформы в ответе моста — `8.3` (заглушка, отдельная задача).
