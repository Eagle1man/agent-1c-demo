# Чек-лист приёмки

**Дата:** 01.11.2026
**Как проверять:** каждый пункт — командой или файлом, а не по словам исполнителя.

## A. Демо готово к показу

- [ ] `py verify_1c.py` → «ПРИЁМКА ПРОЙДЕНА»
- [ ] `py tools\check_panel.py` → «ИТОГ: OK» (26 проверок)
- [ ] `py tools\rehearse.py --runs 1` → 10/10 шагов
- [ ] Панель открывается на `http://127.0.0.1:8077`
- [ ] В шапке: «1С: связь есть · мост 1.0» и свежее время
- [ ] Счётчики не нулевые: документы, контрагенты, позиции
- [ ] График выручки отрисован (24 месяца)
- [ ] Карточка документа открывается по клику и содержит позиции и итог
- [ ] Отчёт за период считает документы и сумму
- [ ] CSV открывается в Excel (BOM, `;`)

## B. Поведение при отказе

- [ ] `py tools\check_offline.py` → 6/6 (скрипт сам закрывает 1С)
- [ ] После скрипта мост поднят: `py tools\epf\test_epf_live.py`
- [ ] На панели с закрытой 1С: плашка «1С: НЕТ СВЯЗИ», числа `—`, причина указана
- [ ] Вопрос про данные без 1С: «1С не ответила», без выдуманных цифр
- [ ] Вопрос по знаниям без 1С: работает (RAG)

## C. Данные и происхождение

- [ ] У каждого блока указан источник и время получения
- [ ] Суммы считаются из позиций документов, а не вводятся вручную
- [ ] Поиск по номеру документа возвращает ровно один документ
- [ ] Поиск по контрагенту возвращает его документы
- [ ] Несуществующий номер даёт понятную ошибку «не найден»

## D. Безопасность

- [ ] В коде нет инструментов отправки команд оборудованию (`SCADA_WRITE_ENABLED = False`)
- [ ] `POST /api/scada/command` в `web_app.py` возвращает 403
- [ ] `1c/АгентМост.bsl` выполняет только `ВЫБРАТЬ`, нет `ИЗМЕНИТЬ/УДАЛИТЬ/ЗАПИСАТЬ`
- [ ] Подтверждение человека для записи проверяется кодом, а не промптом
- [ ] Недоступность ИИ не влияет на оборудование (система только читает)
