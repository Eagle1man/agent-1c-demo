# Пересборка внешней обработки «АгентМост» (.epf)

**Зачем:** epf — бинарный контейнер, модуль внутри не редактируется напрямую. При этом
исправления вносятся в `1c/АгентМост.bsl`, и обработку нужно пересобрать, иначе
1С запускает старый код (так и случилось: epf от 27.09 падал на строке 583,
хотя исходник уже был исправлен).

## Что нужно

- 1С закрыта (учебная версия — один сеанс, база блокируется).
- Платформа: `C:\Program Files (x86)\1cv8t\8.3.27.1508\bin\1cv8t.exe`.
- База: `C:\1c_bases\DemoAgent`.

## Порядок

```powershell
$exe = "C:\Program Files (x86)\1cv8t\8.3.27.1508\bin\1cv8t.exe"
cd D:\agent-1c-demo

# 1. Выгрузить текущую обработку в XML
& $exe DESIGNER /F"C:\1c_bases\DemoAgent" `
  /DumpExternalDataProcessorOrReportToFiles "D:\agent-1c-demo\build\epf_src" `
  "C:\1c_bases\AgentMost.epf" /Out "D:\agent-1c-demo\build\dump.log"

# 2. Заменить модуль формы исправленным исходником (скрипт добавляет BOM и CRLF)
py build\put_module.py

# 3. Собрать новый .epf
& $exe DESIGNER /F"C:\1c_bases\DemoAgent" `
  /LoadExternalDataProcessorOrReportFromFiles "D:\agent-1c-demo\build\epf_src\АгентМост.xml" `
  "C:\1c_bases\AgentMost_fixed.epf" /Out "D:\agent-1c-demo\build\load.log"
```

Признак успеха: в `load.log` — «Загрузка завершена», без строк с ошибками.
Ошибки компиляции модуля 1С печатает в этот же лог с номером строки.

## Проверить перед запуском

```powershell
py build\check_handlers.py   # обработчики формы объявлены в модуле
py verify_1c.py              # маркеры протокола и экранирование кавычек
```

## Открыть в 1С

Файл → Открыть → `C:\1c_bases\AgentMost_fixed.epf` → в поле пути указать
`D:\agent-1c-demo\exchange` → «Запустить мост».

## Грабли, на которые уже наступали

| Симптом | Причина |
|---|---|
| «Ошибка инициализации модуля ... Ожидается символ ','» | `\"` вместо `""` — в 1С обратный слэш не экранирует кавычку |
| Обработка открывается, но кнопки не работают | epf собран из старого модуля; пересобрать |
| «База занята» при сборке | открыт сеанс 1С; закрыть и повторить |
