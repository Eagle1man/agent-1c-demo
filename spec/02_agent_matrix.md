# Матрица агентов и зон ответственности

| Агент | Роль | Основные задачи | Документы 1С | Каналы связи |
|-------|------|-----------------|--------------|--------------|
| **Координатор (Оркестратор)** | Распределение задач между агентами, мониторинг исполнения, разрешение конфликтов, принятие решений при противоречиях целей. | Декомпозиция цели пользователя на подзадачи, назначение агентам, отслеживание сроков, эскалация человеку. | Журнал, отчёты | blackboard, conflicts, human_confirm |
| **Агент-Бухгалтер** | Работа с документами реализации, приходом, расчётами с контрагентами, сверка остатков, формирование проводок. | Получение остатков, создание проводок, контроль оплат. | РеализацияТоваровУслуг, ПоступлениеТоваровУслуг | commands, responses |
| **Агент-Логист** | Планирование отгрузок, контроль сроков доставки, взаимодействие со складом и транспортом. | Резервирование товара, формирование задач отгрузки, контроль статусов. | ЗаказПокупателя, Отгрузка | commands, responses |
| **Агент-Кладовщик** | Учёт движения товаров на складе, приёмка, отгрузка, инвентаризация, контроль остатков. | Подтверждение наличия товара, списание/приёмка, инвентаризация. | ТоварыНаСкладах (регистр) | commands, responses |
| **Агент-Менеджер по закупкам** | Формирование заявок на закупку, выбор поставщиков, контроль цен и сроков поставки. | Заявка на закупку при дефиците, сравнение поставщиков. | ЗаказПоставщику | commands, responses |
| **Агент-Менеджер по продажам** | Работа с клиентскими заказами, контроль оплат, информирование о статусах. | Обработка заказов, проверка оплаты, уведомление клиентов. | ЗаказКлиента | commands, responses |
| **Агент-Аудит/Контроль** | Журналирование всех действий, проверка соответствия правилам, выявление аномалий, отчёты для руководителя. | Лог действий, проверка high-risk действий без подтверждения, аномалии. | Журнал регистрации | journal.jsonl |

## Связи между агентами
- Координатор → все агенты (назначение задач через blackboard).
- Агент-Кладовщик → Агент-Логист (подтверждение наличия товара).
- Агент-Логист → Агент-Бухгалтер (отгрузка → создание документа реализации).
- Агент-Менеджер по закупкам → Агент-Кладовщик (приход товара на склад).
- Агент-Менеджер по продажам → Агент-Логист (заказ клиента → отгрузка).
- Агент-Аудит ← все агенты (журналирование действий).

## Уровни риска и подтверждение
- **low**: проверка связи, чтение данных (запрос_1с) — агент делает autonomously, пишет в журнал.
- **high**: создание документа, отгрузка, закупка — требует подтверждения координатора, а при критически высоком риске — человека (Human-in-the-Loop).
