# Устав проекта: мультиагентное управление на базе 1С:Предприятие

## 1. Цель и ожидаемый результат
Создать мультиагентную систему (MAS), которая координирует несколько специализированных ИИ-агентов для управления взаимосвязанными бизнес-процессами предприятия (закупки → склад → продажи → бухгалтерия) через привычный интерфейс «1С:Предприятие».  
Ожидаемый результат: работающий прототип MAS, среда симуляции предприятия, экспериментальное сравнение «базовый сценарий без агентов» vs «сценарий с агентами» по времени, качеству и затратам, подготовка к пилоту на реальном предприятии.

## 2. Роль руководителя проекта
Руководитель ИИ-проекта personally тестирует агентов, формирует гипотезы, проверяет сценарии, анализирует ошибки, ставит требования, документирует результаты и подготавливает обоснованные предложения. Полномочия на утверждение бюджета, изменение продуктивной 1С и промышленный запуск требуют отдельного согласования со спонсором.

## 3. Решения в рамках компетенции руководителя
- Выбор прототипа и локальной модели (Qwen 2.5:1.5b через Ollama).
- Формирование матрицы агентов и зон ответственности.
- Определение метрик (время, качество, затраты) и базового сценария.
- Оценка пригодности модели для координации агентов.

## 4. Решения, требующие участия специалистов или спонсора
- Инфраструктура для полноценного пилота (отдельная ВМ, vLLM, крупная модель Qwen3.8-27B-1C при необходимости).
- Информационная безопасность, доступ к данным, интеграция с 1С предприятия.
- Выбор площадки и решение о промышленном запуске.
- Поиск предприятия-партнёра для пилота.

## 5. Предлагаемые обязательства спонсора
- Содействие с вычислительными ресурсами.
- Поиск предприятия-партнёра и организация взаимодействия.
- Рассмотрение результатов экспериментов и пилота.

## 6. Условия пересмотра Устава
Перед полноценным пилотом требуется уточнить архитектуру, площадку, показатели, границы автоматизации и ответственность участников.

## 7. Предположения и открытые вопросы
- Конкретные процессы и документы вымышленного предприятия — на этапе уточнения.
- Полная симуляция предприятия — реализация не подтверждена.
- Метод координации агентов — требует разработки.
- Экспериментальный протокол — не сформирован окончательно.
- Исходные показатели эффективности — отсутствуют.
- Пригодность модели для целевой системы — не проверена.
- Предприятие-партнёр — не найдено.
- Формат сотрудничества с Федеральным центром компетенций — не согласован.
