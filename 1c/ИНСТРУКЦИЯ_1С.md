# ИНСТРУКЦИЯ_1С — запуск моста «АгентМост» (для человека без опыта 1С)

Мост — это внешняя обработка 1С, которая раз в 2 секунды читает команды
агента из папки `exchange/commands/` и кладёт ответы в `exchange/responses/`.
Принцип из концепции: агент выполняет работу, человек принимает решения;
создание документов — только с подтверждением человека.

Сеанс 1С с запущенным мостом должен быть открыт всё время работы с агентом.

---

## 1. Где скачать 1С бесплатно

1. Откройте сайт **online.1c.ru**.
2. Найдите раздел учебных и бесплатных версий — **«1С:Предприятие 8. Учебная версия»**
   (формулировка на сайте: **«Учебная версия»**).
3. Скачайте бесплатную сборку «платформа + конфигурация». Для демо подойдут:
   - **«Управление торговлей»** (версия 3.0 / «Управление торговлей 3.0»);
   - «Управление нашей фирмой» (версия 2.0 / «Управление нашей фирмой 2.0»).
4. Установите платформу, затем установите шаблон конфигурации.

Ограничения учебной версии, о которых надо знать заранее:

- лимит выборки — 2000 записей (мост дополнительно режет запросы до 50 строк);
- одновременно работает только **1 сеанс** — поэтому мост запускаем в
  единственном открытом сеансе и не открываем второй.

## 2. Создайте базу

1. Запустите «1С:Предприятие».
2. Нажмите «Добавить» → «Создание новой информационной базы» → «Создание базы из шаблона».
3. Выберите шаблон «Управление торговлей 3.0» (или «Управление нашей фирмой 2.0»).
   Типовой шаблон содержит готовые справочники `Контрагенты` и `Номенклатура`
   и документ `РеализацияТоваровУслуг` — их ищет агент; наполните их примерами
   (несколько контрагентов и номенклатурных позиций) перед демо-показом.
4. Дайте базе имя, например `ДемоАгент`, путь оставьте по умолчанию.
5. Запустите базу в режиме «1С:Предприятие», дождитесь первого открытия.
   Закройте её — дальше нужен **конфигуратор**.

## 3. Откройте конфигуратор

1. В списке баз выберите вашу базу.
2. Нажмите кнопку **«Конфигуратор»** (вторая кнопка рядом с «1С:Предприятие»).
   Именно через **конфигуратор** создаются внешние обработки.
3. Дождитесь открытия окна конфигуратора.

## 4. Создайте внешнюю обработку

1. В меню конфигуратора: **Файл → Создать → Внешняя обработка**
   (тип объекта — **«Внешняя обработка»**).
2. Сразу сохраните: Файл → Сохранить как → `АгентМост.epf` в удобное место.
3. Создайте форму: в дереве обработки правой кнопкой на «Формы» → «Добавить».
4. Подготовьте форму (правой кнопкой на форме):
   - «Реквизиты...» → добавьте реквизит `ПутьКExchange` (тип Строка) —
     это поле, куда вводится путь к папке `exchange`;
   - на форму: поле ввода `ПутьКExchange` и кнопку с заголовком
     **«Запустить мост»** (команда/действие — `ЗапуститьМост`),
     по желанию вторую кнопку «Остановить мост» (`ОстановитьМост`).
5. Откройте файл `1c/АгентМост.bsl` из этого проекта в Блокноте.
   Это один готовый файл; комментарии `МОДУЛЬ ОБЪЕКТА` / `МОДУЛЬ ФОРМЫ`
   в нём служебные: кнопки, таймер и вся логика живут в **модуле формы**
   (форма внешней обработки не видит модуль объекта — особенность 1С,
   поэтому весь код вставляется только в форму).
6. Откройте модуль формы: правой кнопкой на форме → «Открыть модуль» —
   и вставьте туда **весь текст файла целиком**. Модуль объекта заполнять не нужно.
7. Сохраните обработку (Файл → Сохранить), закройте конфигуратор.

Важно: правится только путь к папке `exchange` (строка с ★ в начале
модуля формы). Остальной код менять не нужно.

## 5. Укажите путь к папке exchange

1. Узнайте полный путь к папке `exchange` этого демо-проекта,
   например `C:\1c_agent\exchange`.
2. Вариант А (рекомендуется): в начале **модуля формы** найдите строку
   с ★ (комментарий «★ ЕДИНСТВЕННОЕ МЕСТО ДЛЯ ПРАВКИ ПУТИ») и замените
   `C:\1c_agent\exchange` на свой путь — он используется, если поле формы пустое.
3. Вариант Б: не меняя код — введите свой путь в поле `ПутьКExchange`
   на форме обработки перед нажатием кнопки **«Запустить мост»**
   (значение поля важнее значения по умолчанию).
4. Проверьте, что папки `exchange/commands`, `exchange/responses`,
   `exchange/archive`, `exchange/log` существуют или будут созданы
   автоматически при первом опросе (мост создаёт их сам).

## 6. Сохраните .epf и запустите в 1С

1. В конфигураторе: Файл → Сохранить → получится файл `АгентМост.epf`.
2. Откройте базу в режиме «1С:Предприятие».
3. Откройте обработку: Файл → Открыть → выберите `АгентМост.epf`.
4. В поле пути проверьте путь к `exchange`.
5. Мост стартует сам при открытии формы. Должно появиться сообщение
   «Мост запущен. Опрос папки exchange каждые 2 сек». Кнопка
   **«Запустить мост»** дублирует запуск вручную (если кнопки не видны
   в вашей сборке платформы — это нормально, автозапуск уже работает).
6. **Оставьте этот сеанс открытым.** В учебной версии только 1 сеанс —
   если закрыть окно, мост остановится и агент перестанет получать ответы.

## 7. Как проверить, что мост работает (команда проверка_связи)

Проверка выполняется со стороны агента (вторую половину проекта делает
агент, вам делать ничего не нужно, только наблюдать):

1. Агент кладёт файл `<uuid>.json` с действием `проверка_связи` в `exchange/commands/`.
2. В течение ~2–5 секунд файл должен исчезнуть из `commands/`.
3. В `exchange/responses/` должен появиться файл с тем же именем (`<uuid>.json`)
   со статусом `ok` и полями `platform`, `bsl_version`.
4. В `exchange/archive/` появится копия `<uuid>__done.json`.
5. Если ответа нет дольше 10 секунд — смотрите раздел «Частые ошибки».

Быстрая ручная проверка без агента: создайте в `exchange/commands/` файл
`test.json` с текстом команды `проверка_связи` (подскажет разработчик агента),
подождите 5 секунд и проверьте `exchange/responses/test.json`.

## 8. Частые ошибки

| Симптом | Причина и решение |
|---|---|
| Кнопка «Запустить мост» ничего не делает | Весь код не вставлен в **модуль формы** / код вставлен в модуль объекта (форма его не видит). Проверьте: весь файл `АгентМост.bsl` лежит в модуле формы |
| Файлы лежат в `commands/`, ответов нет | Сеанс 1С закрыт или мост не запущен. Откройте базу, откройте `.epf`, нажмите **«Запустить мост»**, оставьте сеанс открытым |
| Ошибка пути / `io_error` в ответе | Неверный путь к `exchange`. Проверьте поле `ПутьКExchange` на форме и константу в модуле объекта; путь без кавычек на конце без `\` |
| Ответ `parse_error` | Битый JSON команды. Агент перезапишет команду; если повторяется — покажите текст файла разработчику |
| Ответ `invalid_query` на запрос | Запрос не начинается с `ВЫБРАТЬ` или содержит запрещённые слова (`ИЗМЕНИТЬ`, `УДАЛИТЬ` и т.д.) либо `;`. Исправляет сторона агента |
| Ответ `unsupported_doc_type` | В вашей конфигурации нет документа `РеализацияТоваровУслуг` (нормально для части конфигураций, например УНФ). Демо тогда ограничивается чтением и командой `проверка_связи` |
| Ответ `need_confirmation` вместо создания документа | Это не ошибка, а защита: агент должен показать вам эхо (`echo`) и после слов «да/подтверждаю» повторить команду с подтверждением. Документ создастся только после этого |
| «Второй сеанс запрещён» (учебная версия) | Закройте все окна 1С, оставьте только один сеанс с мостом |
| Кодировка / «кракозябры» | Мост читает и пишет строго в UTF-8. Не открывайте файлы обмена в программах, меняющих кодировку |

## 9. Остановка

- Кнопка «Остановить мост» (если добавили) или просто закройте обработку/сеанс.
- Не удаляйте папку `exchange/` — там архив обработанных команд.

Удачной демонстрации: агент работает — человек решает.
